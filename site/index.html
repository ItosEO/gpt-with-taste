# clsx 中文上手指南

`clsx` 用来按条件拼接 CSS 类名，返回一个用空格分隔的字符串。比如按钮始终带有 `button`，选中时再加上 `button--active`。它不生成 CSS，也不依赖 React；在 React 中，把返回值交给 `className` 即可。

本文按本仓库的 `clsx 2.1.1` 编写，适合已经有前端项目、刚开始使用 clsx 的同事。

## 1. 安装并验证

先确认本机有 Node.js 和 npm，然后在前端项目的根目录（有 `package.json` 的目录）运行：

```sh
npm install --save clsx
```

这是应用运行时会用到的依赖，不要加 `--save-dev`。

安装后，在同一目录运行：

```sh
node -e "const clsx = require('clsx'); console.log(clsx('button', { 'button--active': true }));"
```

应输出：

```text
button button--active
```

# clsx 中文上手

当一个元素的类名要随状态变化时，用 `clsx` 把固定类名和条件类名拼成一个字符串，再交给 `className`。它只负责拼类名，样式仍由你项目中的 CSS 提供。

## 1. 安装并跑通第一个例子

在已有前端项目的根目录（包含 `package.json` 的目录）运行：

```sh
npm install --save clsx
```

在项目的 JavaScript 或 TypeScript 文件中导入：

```js
import clsx from 'clsx';

const isActive = true;
const isDisabled = false;

const className = clsx('button', {
  'button--active': isActive,
  'button--disabled': isDisabled,
});

console.log(className);
// 输出：'button button--active'
```

把 `isActive` 改成 `false`，结果就只剩 `'button'`。在项目现有的开发环境中运行这段代码，查看控制台输出即可确认。
